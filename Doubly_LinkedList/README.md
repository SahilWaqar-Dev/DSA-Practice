## Doubly Linked List

Here is the Code of doubly linked list having start and end reference and in this each node consist of three things the one thing is the data and the other two things are the references of previous and next node which resolves the issue of the time complexity in doubly linkedList

- insertatstart
- insertatend
- deleteatstart
- deleteatend

all the above four methods have the time Complexity O(1)
