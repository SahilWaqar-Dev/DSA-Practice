#  Stack 

Stack is the collection of objects in such a way that the last element inserted will remove first and the first inserted will remove at last.

Stack follows a **LIFO** structure:
- means **Last In First Out**.

We can understand a stack like a simple `Ctrl + Z` is a stack, the operation performed at last will remove first.
