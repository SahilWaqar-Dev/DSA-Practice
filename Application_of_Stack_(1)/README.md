### 1. Expression Conversion (Infix to Post/Prefix)

as to represent any equation there are many ways as if we want to add 2 numbers we can use `a+b` but it is considered as the worst equation so we will convert this equation into Post and prefix to solve the equation efficiently. 

- In **postfix**, the operator is written after both operands.
- In **prefix**, the operator is written before the operands.
